# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report a suspected vulnerability or exposed secret to Voyage at security@vyg.co.nz. Tell us what you found, where, and how to reproduce it.

You can also report it privately on GitHub: open this repo's Security tab and choose "Report a vulnerability".

Voyage staff: report it in the internal incident channel straight away, as set out in section 11 of the Voyage Information Security Framework.

## What happens next

We'll acknowledge your report and keep you updated while we investigate.
